# pocket-money-manager
Python으로 파일 입출력 기반의 가계부 콘솔 프로그램을 구현하는 과제입니다.
머릿속에서 데이터가 어떻게 생성되고 이동하는지 말로 짚어보는 의사코드(Pseudocode) 흐름입니다.

---

### 용돈기입장 5분 MVP 말로 쓴 수도 코드

1. **상태 준비**
* 시작할 돈(잔액)을 10,000원으로 정해둔다.
* 지출들을 담아둘 빈 상자(리스트)를 하나 마련해둔다.


2. **사용자 입력**
* 사용자에게 "어디에 썼는지(내용)" 글자로 묻고 기억한다.
* 사용자에게 "얼마를 썼는지(금액)" 숫자로 묻고 기억한다.


3. **핵심 연산 & 기록**
* 원래 잔액에서 입력받은 금액을 뺀다.
* [내용, 금액] 한 묶음을 장부 상자(리스트)에 쏙 집어넣는다.


4. **결과 확인**
* 줄어든 새 잔액을 화면에 보여준다.
* 장부 상자에 방금 쓴 내용이 잘 들어갔는지 열어서 보여준다.
